## ✨ Features

- 🎨 Modern UI with Tailwind CSS
- 📱 Fully Responsive
- 🔐 JWT Authentication (Login/Register/Logout)
- 👑 Admin Dashboard
- 📁 Project Management (CRUD)
- 📧 Contact Form with Email
- 🎯 Framer Motion Animations
- 📊 Role-based Access (User/Admin)

## 🛠️ Tech Stack

### Frontend
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion
- React Router DOM
- Axios
- Lucide Icons
- FontAwesome

### Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Bcrypt
- Nodemailer
- Multer
- ImageKit
